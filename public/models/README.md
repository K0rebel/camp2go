# Katalog Modeli 3D (Camp2Go)

Domyślnie aplikacja renderuje zoptymalizowany pod kątem WebGL/PBR model przyczepy ze wszystkimi detalami (okna, bakista z gazem, koło manewrowe, podpory stabilizujące, movery, zawory wody, wnętrze).

## Jak wgrać własny model 3D (opcja dla zaawansowanych):
1. Umieść plik modelu w formacie `.glb` w tym katalogu pod nazwą `caravan.glb` (`public/models/caravan.glb`).
2. Dostosuj ewentualne współrzędne kamery i hotspotów w pliku `src/config/stepsConfig.ts`.
